# 褒めキレゲーム 要件定義書

## 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| アプリ名 | 褒めキレゲーム |
| プラットフォーム | iOS |
| 言語 | 日本語のみ |
| ジャンル | パーティーゲーム |
| 対象ユーザー数 | 2〜10人（同一画面を囲んでプレイ） |

### アプリ概要
お題（一般的な事象の画像＋名称）と、「褒め」または「キレ」の指示がランダムに表示される。
プレイヤーはその指示に従ってリアクションを行い、場の盛り上がりを競うパーティーゲームアプリ。

---

## 2. ゲームフロー

```
[ホーム画面]
    ↓ ゲームスタートボタン
[カウントダウン画面]（3・2・1）
    ↓
[ゲーム画面]
  - お題カードを1枚表示（10秒）
  - 10枚終わるまで繰り返す
    ↓
[ふりかえり画面]
  - 今回出た10枚を一覧表示
    ↓ 「もう一度」or「ホームへ」
```

---

## 3. 画面設計

### 3-1. ホーム画面
- アプリタイトル表示
- 「ゲームスタート」ボタン

### 3-2. カウントダウン画面
- 「3・2・1・スタート！」のカウントダウン表示

### 3-3. ゲーム画面（メイン）
| 要素 | 詳細 |
|------|------|
| 枚数インジケーター | 「4 / 10」のように現在の枚数を表示（丸囲み数字） |
| お題画像 | 画面中央に大きく表示 |
| お題名称 | 画像下部または上部にテキストで表示 |
| 褒め/キレ表示 | 画面左端に縦書き大文字で「褒め」または「キレ」 |
| 枠の色 | 「褒め」→ 青系、「キレ」→ 赤系 |
| タイマー | 10秒カウントダウン（プログレスバーまたは数字） |
| 自動送り | 10秒後に次のカードへ自動遷移 |

### 3-4. ふりかえり画面
- 今回のゲームで出た10枚のカードをグリッドまたはリスト表示
- 各カードに「お題名称」と「褒め/キレ」を表示
- 「もう一度」ボタン → ゲーム画面へ
- 「ホームへ」ボタン → ホーム画面へ

---

## 4. 機能要件

### 4-1. お題管理
| 要件ID | 内容 |
|--------|------|
| F-01 | お題は画像＋名称のセットで200枚をアプリにバンドルする |
| F-02 | 1ゲームあたり、200枚の中からランダムに10枚を重複なく選ぶ |
| F-03 | 200枚をすべて使い切るまで同じお題は出ない（デッキ方式） |
| F-04 | 200枚を使い切ったら自動的にシャッフルして再利用する |
| F-05 | デッキ状態はアプリを閉じても保持する（永続化） |

### 4-2. 褒め/キレ判定
| 要件ID | 内容 |
|--------|------|
| F-06 | 1枚ごとに「褒め」か「キレ」をランダムで割り当てる |
| F-07 | 1ゲーム内での褒め/キレの偏りは許容する（純粋ランダム） |

### 4-3. タイマー
| 要件ID | 内容 |
|--------|------|
| F-08 | カード表示後、10秒で自動的に次のカードへ遷移する |
| F-09 | タイマーはユーザーに視覚的にわかるよう表示する |

### 4-4. ふりかえり
| 要件ID | 内容 |
|--------|------|
| F-10 | ゲーム終了後、出題された10枚の一覧を表示する |
| F-11 | 各カードのお題名称と褒め/キレを確認できる |

---

## 5. 非機能要件

| 要件ID | 内容 |
|--------|------|
| NF-01 | オフラインで動作すること（通信不要） |
| NF-02 | 画像はすべてフリー素材を使用すること |
| NF-03 | iOS 16以降を対象とする（要確認） |
| NF-04 | 画面の向きは横向き固定または縦向き固定（要確認） |
| NF-05 | スリープ防止（ゲーム中は画面が暗くならないようにする） |

---

## 6. データ設計

### お題データ構造（JSON）
```json
{
  "id": 1,
  "name": "ピクニック",
  "imageName": "picnic"
}
```

### デッキ永続化データ
- 残りデッキ（未出題IDのリスト）をUserDefaultsまたはファイルで保存
- ゲーム開始時に10枚を取り出し、デッキを更新して保存
