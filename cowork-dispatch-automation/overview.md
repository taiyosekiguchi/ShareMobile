# Cowork / Dispatch — モバイル→PCリモート自動化システム 概要

## ツール概要

| ツール | 役割 | 動作環境 |
|--------|------|---------|
| **Dispatch** | 指示を送る（モバイルアプリ） | スマホ |
| **Cowork** | 指示を受けて実行するAIエージェント | PC（ブラウザ操作含む） |

**使い方のイメージ**:
```
スマホから「〇〇して」と送信
    ↓（Dispatch経由）
PCのCoworkがブラウザを操作して実行
    ↓
結果がファイルやポストとして完成
```

飲みに行っている途中に送って、家に帰る前に完成している、というリモート非同期実行が特徴。

---

## Claude Code（ターミナル）との違い

| 項目 | Claude Code | Cowork / Dispatch |
|------|------------|-------------------|
| 操作起点 | PC（ターミナル） | スマホ（Dispatch） |
| ブラウザ操作 | 基本なし | ✅ Chrome直接操作 |
| API不要のSNS投稿 | 困難 | ✅（ブラウザ経由で直接投稿） |
| ファイル・コード操作 | ✅ 得意 | △ |
| 外出中の遠隔操作 | 難しい | ✅ |

> **使い分けの考え方**: APIが使えるならClaude Code。ブラウザを直接触る必要があるならCowork。

## 実証されたユースケース

### 1. Xリサーチ（30分で完了 / 手動なら2〜3時間）

**指示**: 「XでAI関連のバズポストを調べて」

**Coworkの実行ステップ**:
1. Chromeを自動で起動
2. Xで検索 → 話題タブに切り替え
3. 日本語バズポストを5件抽出
4. 各ポストの URL / いいね数 / テーマ / 伸びた理由を分析
5. マークダウンファイルに保存

**出力物**: 分析レポート（.md）

---

### 2. 連結リプライの投稿

**指示**: 特定のポストに連結リプを投稿

**Coworkの実行ステップ**:
1. 対象ポストを開く
2. リプ欄の雰囲気を確認
3. 公式サイトで関連情報を調査
4. 5つの連結リプを作成
5. 承認後、1つずつ順番に投稿

**ポイント**: ブラウザを直接操作して投稿するため、コピペすら不要。API不要。

---

### 3. バズポスト案の量産

**指示**: タイムラインを分析してバズりそうなポスト案を10個作成

**Coworkの実行内容**:
- タイムラインのトレンド確認
- 過去ポストのエンゲージメント分析
- ターゲット層の特定
- ポスト案10件を出力

---

### 4. 記事の作成・リライト

**実行例**:
- 特定の書き手の記事手法を分析 → セールスレター型の記事を作成
- 「AI臭い」フィードバック → 文体を徹底的に書き直してv2を出力
- CTA記事3本のリライトを同時並行で実行
- Xでバズっている記事（最大4.3万いいね）を分析 → バズ要素を記事に反映

**フィードバックループ**: 人間が簡単な指示（「AI臭い」など）を送るだけで修正版が出てくる

---

### 5. スライド作成

**指示**: 手書きノートの写真を送って「スライドにして」

**出力**:
- 1回目: 10枚のプレゼン（ダークテーマ、アイコン付き）
- 修正フィードバック後: 14枚に拡張されたv2
  - クイズ形式のスライド追加
  - 答え合わせページ追加
  - 裏宿題スライド追加

**入力**: 写真1枚 → **出力**: 完成したプレゼン資料

---

### 6. スキル化（ワークフローのパッケージング）

**指示**: 「この一連の作業をスキルにして」

**Coworkの実行**:
- `SKILL.md` ファイルを作成
- 一連のワークフローをパッケージ化

**効果**: 次回からは一言でワークフロー全体が走る

---

## スキル化（SKILL.md）の仕組み

```markdown
# SKILL: [スキル名]

## トリガー
「〇〇して」と言われたら実行

## ステップ
1. ...
2. ...
3. ...

## 出力
- 成果物の形式
```

このファイルを作成することで、複雑な手順を1つのコマンドとして再利用できるようになる。
Threadsの6エージェントシステムにおける「ナレッジとロジックの分離」と同じ発想。

---

## Threads自動化システムとの組み合わせ方

| 用途 | 推奨ツール |
|------|-----------|
| Threads/X へのAPI投稿 | Claude Code（6エージェント） |
| X のリサーチ・ブラウザ操作 | Cowork |
| 記事・スライド作成（モバイルから指示） | Cowork + Dispatch |
| バズ投稿の分析 → 次の投稿に反映 | Cowork（分析）+ Claude Code（投稿） |
| スマホから遠隔でタスクを投げる | Dispatch → Cowork |

---

## Claude Codeへの実装ヒント

Cowork/Dispatchの機能を部分的にClaude Codeで再現する場合:

```
ブラウザ操作が必要な部分:
→ Playwright / Selenium をClaude Codeに書かせて実行させる

スマホからのリモート指示:
→ Claude Code + Webhook（例: LINE Bot / Slack Bot）で代替可能

SKILL.md相当の仕組み:
→ Claude Codeの /memory や CLAUDE.md にワークフローを記述
```

### CLAUDE.md でのスキル定義例
```markdown
## スキル: Xリサーチ

「Xリサーチして」と言われたら以下を実行:
1. playwrightでXを開き、指定キーワードで検索
2. 話題タブのトップ5件を取得
3. URL / いいね数 / テーマ / 伸びた理由を抽出
4. research/YYYY-MM-DD.md に保存
```
